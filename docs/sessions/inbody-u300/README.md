## Summary

InBody 전략적 파트너십을 향한 AI 라이브 무브먼트 코칭 피치덱. rack-tracker 저장소의 `slides-react` 앱에서 이식했다. 이식 시 단일 앱 구조에 맞춰 슬라이드를 `slides/`, 이미지를 `assets/` 로 분리하고 이미지 import 경로를 `../assets/` 로 재작성했다.

## 청중 / 목적

- 청중: InBody 의사결정자(파트너십·투자 관점).
- 목적: 부상·성과 문제 → 솔루션/핵심기술 → 시장·BM → Why Now/경쟁 → InBody 시너지 → 팀/비전 의 메시지 아크로 파트너십 제안.

## 자산 메모

- 이미지: `app/src/sessions/inbody-u300/assets/` (인물 사진, 로고, 도식 등). 슬라이드에서 `import x from '../assets/<file>'`.
- 인물/로고 이미지는 원 출처(InBody 피치 자료)에서 가져온 것으로, 외부 공개 전 라이선스/동의 확인이 필요할 수 있다.

## Notes

- 이 세션은 rack-tracker 의 디자인 토큰(InBody 3-color)을 그대로 사용한다. 공용 `tokens.css` 가 InBody 색을 기본값으로 둔다.
- 다른 세션이 InBody 색을 원치 않으면 그 세션 스타일에서 토큰을 override 한다.
