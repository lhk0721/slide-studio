# Deck Design·Build 작업방식 복기 — 자동화 참고 노트

`financial-market` 파일럿에서 **Phase 4(디자인 시스템) → Phase 5(빌드)** 를 실제로 수행하며 드러난 작업방식의 복기. 규칙이 아니라 **사례 관찰 + 자동화 설계 참고**다(`deck-discovery-insights.md`·`deck-content-insights.md`와 같은 성격). 규칙은 `deck-design.md`·`slides-jsx-convention.md`에 있고, 이 문서는 "어떻게 일했나 / 무엇을 자동화하면 되나"를 남긴다.

## Document Relations

- 규칙(이 복기가 가리키는 것): `deck-design.md`(Phase 4), `slides-jsx-convention.md`(Phase 5 + 자가검수)
- 형제 인사이트: `deck-discovery-insights.md`, `deck-content-insights.md`

## 1. 실제로 따른 흐름

콘텐츠 게이트 통과(준비 11/12, 미검증 0) 뒤:

1. **override 아키텍처 결정**(전역 1회) → 세션별 `tokens.css` + `[data-theme]` 스코프, 앱-셸 폴백 분리.
2. **토큰 델타 결정** → 단일 accent(Oxblood)만 갈라짐, 골격 토큰 불변.
3. **패턴 카탈로그 확정**(`design.md` D3) → 무엇을 shared 승격/세션-로컬/재사용할지.
4. **build-first 빌드** → 가장 정의적인 슬라이드(s10 종합)부터, 두 번째 소비자에서 공용 컴포넌트 추출(`DivergenceFlow`).
5. **슬라이드마다 자가검수 루프** → 통과 후 커밋.

각 화살표는 **사용자 명시 승인**으로 넘어갔다(브리프·콘텐츠와 같은 게이트 철학).

## 2. 핵심 메커니즘 (자동화 가치 순)

### ① 자가검수 루프 — 가장 자동화 가치가 큼

`build → 헤드리스 캡처(npm run shot) → PNG를 읽어 디자인 규율 대비 트집 → 수정 → 재캡처`. 이게 이번 작업 품질의 핵심이었다. **코드가 빌드된다 ≠ 화면이 맞다.** 추론만으로는 구조 결함 정도만 잡히고, 미세 정렬·여백·중복은 **렌더를 봐야** 잡힌다.

- 도구: `app/scripts/shot.mjs`(Vite를 스스로 띄워 `[data-deck-frame]` 1280×720 프레임만 캡처). `waitUntil:'commit'` + 셀렉터 대기(고부하 대비 45s)로 안정화.
- 체크리스트: `slides-jsx-convention.md` "자가검수"(정렬·단일 강조·보더보다 여백·프레임 오버플로우·`\n`→pre-line·export 패리티).
- **자동화 핵심**: 이 루프는 사람 없이 돌릴 수 있다(캡처는 결정론적, 비평은 체크리스트 기반). LLM이 캡처를 읽고 체크리스트로 self-critique → 자동 수정 → 재캡처. 사람은 최종 승인만.

### ② 선택지로 되돌려주기 — 결정의 기본형

색·아키텍처를 LLM이 임의 확정하지 않고 **후보 N개(추천 1개 + 프리뷰)**를 제시 → 사용자 선택 → `design.md`에 **선택 + 탈락 선택지까지** 기록(provenance). 예: override 아키텍처 3안, accent 4안(Teal/Navy/Amber/Oxblood). 탈락 이유를 남기면 후반 재논의가 막힌다.

### ③ build-first + 두 번째-소비자 추출

가장 어려운 슬라이드부터 만들어 패턴을 확립하고, **speculative 공용화는 금지**. 두 번째 소비자가 등장할 때 추출(s10에 인라인했던 분기 도식을 s2 빌드 시 `DivergenceFlow`로 추출). 덕분에 추상화가 실제 사용처 2곳을 보고 설계됐다.

### ④ 미러 슬라이드 — 대칭으로 가속

비교 덱은 한쪽(미국 3부작: 자본집중/붕괴/트레이너=자산)을 먼저 만들고, 반대쪽(한국 3부작: 파편화/폐업/트레이너=비용)을 **같은 아키타입의 거울**로 빠르게 채웠다. 차트+캡션·Asset/Cost 패턴을 그대로 재사용.

## 3. 확립된 재사용 패턴 (라이브러리)

| 패턴 | 거처 | 쓰임 |
| --- | --- | --- |
| `DivergenceFlow` | 세션-로컬 컴포넌트 | 공통 충격 → accent 분기선 → 두 컬럼 헤드 (s2·s10) |
| `.s-source` | app-wide `shared.css` | 슬라이드 하단 출처 각주 1줄 |
| 차트+캡션 아키타입 | per-slide 조합 | 차트 SVG(~1.5) \| metric 캡션(~1) — 차트가 hero 수치 소유, 캡션은 보완(ink) (s4·s5·s7·s8) |
| 대칭 2단 비교 | `col-grid g2` + 중앙 축 라벨 | 좌우 행 정렬(s10) |
| Asset/Cost 카드 | per-slide | 중립 목록 \| accent-soft 카드 (s6, s9는 거울=인과 체인) |
| 도넛 / 막대(상승·하락) | SVG, 클래스 stroke | 분산·붕괴·폐업 (s5·s7·s8) |
| 아이콘 카드 | 인라인 SVG(accent stroke) | 시사점 (s11) |

차트 SVG는 **클래스 기반 fill/stroke**로 줘서 내보내기(`exportSlides.jsx`)에 보존되게 했다.

## 4. 스케일에 기여한 규율

- **한 슬라이드 한 강조**: accent(Oxblood)는 한 색·한 초점. 차트는 hero 수치를, 캡션은 보완 사실을 ink로 — **같은 수치 중복 금지**(s4 자가검수로 교정).
- **보더보다 여백**: 구분은 거터·여백. 시스템에도 적용 — 공용 클래스 남발 금지(app-wide 신규는 `.s-source` 1개).
- **불변 토큰**: 타이포·여백·그리드·radius는 세션 간 고정. 색·폰트·밀도만 갈라짐.
- **정직성**: 미검증 근거는 verify로, 자산 라이선스는 그대로 기록(표지 사진=김포신문 보도사진 → 이용 허락 확인 필요로 명시). 데이터는 schematic이라도 출처 수치에 기반.

## 5. 자동화 설계 시 고려 — 무엇을 자동화 / 무엇이 사람 몫

**자동화 가능**:
- 자가검수 루프(캡처→체크리스트 비평→수정→재캡처).
- 미러 슬라이드 생성(한쪽 아키타입 → 반대쪽 데이터 매핑).
- 패턴 인스턴스화(차트+캡션·2단 비교 등에 slide 메타의 `body`/`evidence`/`assets`를 주입).
- 빌드·렌더 회귀 점검(리팩터 후 캡처 diff).

**사람 확인 필요(게이트)**:
- 색·아키텍처 등 **취향/전략 결정**(선택지 제시 후).
- 자산 **라이선스·출처** 판단(보도사진·스톡·촬영).
- **사실/시점 의존 수치**(발표 시점 재확인).
- 최종 디자인 승인.

**입력 아티팩트(머신 리더블)**: `brief.md`(메시지) → slide 메타(`group/role/message/evidence/assets/body`) → `design.md`(토큰·패턴·계약). 이 체인이 있으면 빌드 단계는 "메타 + 패턴 + 자가검수"로 상당 부분 기계화된다.

## 6. 자가검수가 실제로 잡은 것 (루프의 가치 증명)

추론만으로는 못 봤고 **렌더 대조로** 잡힌 사례:

- **s4**: hero 수치(493억$)가 차트와 캡션에 **중복** → 캡션 수치 제거, 강조 일원화.
- **s6**: Asset 카드가 `align-self:stretch`로 전체 높이를 채워 **빈 박스**가 큼 → 콘텐츠 높이로.
- **s2**: 콘텐츠가 세로로 떠 **빈 공간 과다** → 결말 확대·헤드↔결말 틱·2줄 포컬로 균형.
- **s10(최초)**: 분기선이 컬럼 중심을 가리키는데 텍스트는 좌측정렬, 레인 독립이라 **행 미정렬** → 공유 그리드(중앙 축 라벨)로 재설계.

공통점: **레이아웃·정렬·중복·여백** 결함은 코드 리뷰로 안 보이고 캡처로 보인다. → 자가검수 루프가 없으면 이 결함들이 그대로 나간다.

## 7. 커밋·로깅 리듬

- **작업 단위 = 커밋 단위**(슬라이드 1~3장 또는 한 결정). 매 단위 캡처 자가검수 → 사용자 승인 → `docs/issues/`(여기선 #2)에 로그 → 커밋.
- 결정은 `design.md` 결정 로그에, 진행은 세션 `README.md`에, 작업 내역은 이슈 관리문서에. 셋이 단일 소스를 가리키게 유지.

> 한 줄 요약: **선택지로 결정하고, 패턴으로 만들고, 캡처로 스스로 검수한다.** 이 셋이 이번 덱(12/12)을 굴린 엔진이며, 그대로 자동화 파이프라인의 골격이 된다.
